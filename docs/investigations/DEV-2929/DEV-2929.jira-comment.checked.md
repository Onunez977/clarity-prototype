**Approach**

Change two calls inside LprRepossessions::exportAction(): the static `->tooltip('Export as CSV')` becomes an inline closure, and so does the export-day `->fileName(...)`. Both read the existing exportWindow(), which is the same window exportRowsSql() sends to the query. Rows and query therefore can't drift from what the file and tooltip say.

Month filters are labelled from the full UTC calendar month, matching the chart and description. Today and Last 7d use the viewer's local days. Each bound is formatted in its own zone and is never converted.

The tooltip updates on toggle because the heading rebuilds the action on every render after the existing refresh-dashboard handler sets the date.

No new helper, class, constant or config.
