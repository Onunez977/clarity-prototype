**Root cause:** the admin "Bird's Eye" map's `noKitsReporting` computed (App.vue) had no signal for
"has the initial driver-positions fetch resolved yet", so an empty `driverPositions` read as
"genuinely empty" during the mount-order race and the "No kits reporting GPS" notice flashed on load.

**Fix (client-only, 2 files):**
- `stores/map.js` — new `positionsLoaded` ref, set true after the first `fetchDriverPositions()`
  attempt (success or caught error), exported.
- `App.vue` — `noKitsReporting` now also requires `positionsLoaded`; a bare centered `animate-spin`
  spinner renders while `adminMode && liveMode && !positionsLoaded`.
