Portal PWA Wireframes — Landscape Tablet & Laptop Optimized

Clickable wireframes designed for iPad landscape (1024×768) and laptop (1366×768) touch-screen viewports. All controls maintain 44–48px touch targets. Layouts use side-by-side panels to leverage landscape screen real estate. The portal is a Vue 3 PWA used by field operators with LPR kits. The scan gridding map is integrated into Trip History — selecting “Today” shows the current active trip with a live map view.

  • Top-level screen switching via the tab bar above the device and the horizontal nav inside the application shell.
  • Login screen shows a focused sign-in form. Access is validated server-side before granting entry to data-bearing screens.
  • Dashboard uses a 4-column metric row spanning full width, with summary actions beside operational details.
  • Trip History integrates the scan gridding map directly. “Today” is the default preset and represents the current active trip, showing live trip stats, an embedded geohash-5 hit heatmap with fullscreen expansion.
  • Other trip presets (This Week, Last Week, Month) show historical trip list cards with a “View Map” action on each card.
  • Near-real-time indicator: GPS data has a 1–3 minute delay, shown as a persistent badge in the top bar on trips and dashboard screens.
  • All chip and button controls are 44–48px minimum for reliable iPad and laptop touch interaction.
  • No phone-style bottom navigation — instead, a horizontal top nav bar sits below the application header for fast screen switching via touch.

Shared Async States

Reusable loading, empty, and error treatments applied consistently across all screens. Each state preserves navigability and provides actionable next steps.

Loading state

Fetching tenant metrics, map layers, and trip summary records. Progress indicator remains visible with concise status text.

Layout structure is preserved during load. Navigation remains available so the operator can switch screens.
Empty state

No trips or scans found for the selected preset. Prompt user to switch presets or expand date window. Metric labels remain visible for comprehension.

Error state

Map service timeout or partial data import. Preserve existing filters and offer explicit retry action. States the age of incomplete data explicitly.
