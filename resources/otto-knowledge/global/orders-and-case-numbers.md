# Orders and case numbers

When someone says **order**, they mean an **RDN case number**.

**RDN** is the **Recovery Database Network** (https://recoverydatabase.net). Repo companies use it as case management for repossession orders.

Clarity stores that case number on the matching **hotlist** entry as the **external order ID**. An order, a case number, and an RDN case number are the same value. To look up an order, search hotlist entries by that external order ID.
